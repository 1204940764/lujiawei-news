## ✨ 3D 图书馆版核心特性

- **宽阔双层大学图书馆大厅**
  - 棕色实木拼接地板、挑高胡桃木吊顶与立柱、复古黄铜吊灯、左右及后方双层回廊书架与 18 张自习长桌，支持 **360° 自由旋转、抬头仰望与缩放漫游**。
  - 三联挑高全景落地窗外呈现秋日校园景致，夜景模式下窗外持续绽放绚丽的 3D 礼花烟花。
  - 右上角支持一键切换 **「👥 有人自习」**（馆内 16 位同学共同自习）与 **「🪑 无人静谧」**（独享深夜空馆）。
- **桌面 7 本实体 3D 书本与真翻页体验**
  - 分别对应 **数据结构、计算机组成原理、操作系统、计算机网络（408 四科）** 与 **数学二、英语二、思想政治理论**。
  - 点击任意书本自动飞起并**平滑展开封面**，内容直接以高清排版呈现在左右书页上；点击左右书页或按方向键 `←` / `→` 触发 **3D 真翻页动画**；翻到资料页后**直接点击书页上的资料卡片即可一键下载**对应 `.xmind` / `.pdf` / `.md` 或打开网盘链接；点击空白处或按 `ESC` 合上书本飞回桌面原位。
- **书桌趣味交互彩蛋 & 拟真 Foley 音效**
  - **💡 极简设计师台灯**：点击切换 **舞台聚光（夜景 + 烟花）** 与 **秋日柔光（白天）**。
  - **☕ 咖啡杯**：点击抬杯轻啜休息（喝满 4 口自动续杯），联动右上角「☕ 咖啡休息中」状态与暖心鼓励语录。
  - **✏️ 笔筒**：点击笔杆错落抖动并开启「✏️ 专注学习」实时计时器。
  - **📝 便利贴 & 🌱 小多肉**：点击触发弹性动画并随机弹出通用鼓励语录。
  - **🏆 419 成绩单立牌**：点击查看初试成绩单、择校建议、省钱技巧与备考心得。
  - 内置纯 Web Audio API 物理建模 + 书房空间混响音效引擎，覆盖翻书、合书落桌、台灯开关、瓷杯轻碰、笔筒抖动、便签翻动等全部交互。
- **全端自适应 & 性能优化**
  - 自动适配桌面宽屏、平板与手机竖屏 3D 机位与触控交互。
  - 单主灯阴影、背景轻量化材质、自适应 30/60fps 帧率及后台标签页零渲染功耗。

## 🚀 本地运行

纯静态原生 HTML + ES Modules，无需构建工具，在仓库根目录启动任意静态服务器即可预览：

```bash
python3 -m http.server 8765
```

浏览器访问 `http://localhost:8765/`（2D 版）或 `http://localhost:8765/3d.html`（3D 版）。
